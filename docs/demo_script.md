# 3-minute demo script – Tessera

**0:00–0:25 – Overview.** "SMEs in Ghana often apply for an AfCFTA certificate of origin without knowing if their product qualifies. Tessera checks products of HS heading 19.01 before they apply." Select stages 2 and 3 in "How the service works" to show the AI tasks.

**0:25–1:00 – Test 3, case T3c (Navigator).** 1 Inputs: realistic synthetic documents. 4 Adviser view: technical overview and the calculation – 15.1% of the ex-works price. 5 SME view: likely NOT to qualify, with the action "reduce the premix by at least GHS 40 per batch".

**1:00–1:20 – Case T3b.** Exactly 15.0% – likely to qualify; the gauge shows the margin.

**1:20–1:40 – Test 4.** No imported 19.01 ingredient, but only simple operations – likely NOT to qualify.

**1:40–2:20 – Adviser view, Test 5 (T5b).** The adviser checks the HS code against the quotes from the SME's documents, answers "citation enough?" and "HS code correct?", and the action button changes (approve / ask the SME / run again). The smudged value gives "Further information required"; the SME view lists the information needed.

**2:20–2:40 – Evaluation set (E04, E05).** Contradictory documents: units in kg and bags; different values on the BOM and the invoice.

**2:40–3:00 – Test log and Monitoring.** 21 of 21 cases agree with the answer key; SME documentation deficiencies by type; the monitoring page shows corrections and bug reports.
